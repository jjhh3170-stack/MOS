## 10.1 The Two-Terminal MOS Structure (2단자 MOS 구조)

### MOS 구조 (slide 4)
**MOS = Metal – Oxide – Semiconductor** (금속–산화막–반도체) 3층 샌드위치.
```
  ┌──────────────┐  ← Metal (게이트 금속)
  ├──────────────┤  ← Oxide (SiO₂), 두께 tox, 유전율 εox
  │ Semiconductor│  ← 반도체 기판 (Si)
  └──────────────┘
```
- 금속/반도체 두 단자 사이에 절연막 → **MOS 커패시터** (2단자 소자).
- Cox = εox / tox (단위면적당 산화막 커패시턴스) — 뒤에서 핵심.
- 게이트 전압으로 반도체 표면 상태(축적/공핍/반전)를 제어 = MOSFET의 원리.

### 전계효과와 표면 상태 — p형 기판 (slide 5~6)
| 게이트 전압 | 표면에서 일어나는 일 | 상태 |
|---|---|---|
| 음(−) | 정공(다수)이 표면에 쌓임 | **축적 (accumulation)** |
| 작은 양(+) | 정공이 밀려남 → 억셉터 음이온(Na⁻)만 남음 | **공핍 (depletion)**, 폭 x_d |
| 큰 양(+) | 표면에 전자(소수)가 모임 = 채널 | **반전 (inversion)** |

- **축적층**: 산화막 아래 다수캐리어가 평형농도보다 많이 쌓인 층.
- **공핍층 = 공간전하영역**: 같은 영역. 캐리어 비움(공핍) ⟺ 고정 이온전하 노출(공간전하).
  - p형 공핍층 고정전하 = 억셉터 음이온 Na⁻.
- **반전층 ≠ 공핍층**: 반전층은 공핍층 위에 추가로 생기는 (움직이는) 소수캐리어 층.

### 에너지 밴드 (p형, slide 7) — 핵심: E_F는 안 휜다
- **열평형 ⟺ 순 전류 0 ⟺ E_F 전체 일정(평평).**
  - E_F는 전자의 전기화학 포텐셜. 차이가 있으면 전류가 흐름 = 비평형.
- E_c, E_v, E_Fi는 국소 전위 −eφ(x)에 묶여 **같이 휨**. 밴드 휨 = "E_F에 대한 E_Fi의 이동량".
- MOS 커패시터는 게이트에 전압을 걸어도 **산화막이 전류를 막아** 순 전류 0 → 평형 유지 → E_F 평평.
  (밴드 휨 = 전위차 존재, E_F 평평 = 전류 0. 두 조건은 동시 성립, 모순 아님.)

**p형 기판 요약 (암기):**
```
음(−) → 밴드 위로 휨 → 축적
양(+) → 밴드 아래로 휨 → 공핍 → (더) → 반전(채널)
```

### n형 기판 (slide 9, 그림10.6) — 부호 전부 반대
| | 축적 | 공핍/반전 |
|---|---|---|
| p형 기판 | 음(−) | 양(+) |
| n형 기판 | 양(+) | 음(−) |
- n형 공핍층 고정전하 = 도너 양이온 Nd⁺ ("유도된 양의 공간전하영역").
- n형 반전층 = 정공(큰 음 전압에서).

## 10.1.2 공핍층 두께 (slide 10 + 교재 380~381쪽)

### 식 (10.4) — 페르미 전위 φ_fp
```
φ_fp = V_t · ln(N_a / n_i)
```
- V_t = kT/e ≈ 0.0259 V (300K). 도핑 N_a↑ → φ_fp↑ (더 강한 p형).
- bulk에서 E_Fi와 E_F의 전위차.

### 표면전위 φ_s (그림 10.8)
- 표면에서 E_Fi가 bulk 대비 휜 양 = 공핍층 양단 전위차.
- 게이트 전압↑ → φ_s↑ → 공핍폭 x_d↑.

### 식 (10.5) — 공핍폭 (계단 공핍 근사)
```
x_d = √( 2·ε_s·φ_s / (e·N_a) )
```
- PN 접합 공핍폭 공식과 동형 → "같은 차수".
- 도핑 N_a↑ → x_d↓ (분모).

### ★ 문턱 반전점 (그림 10.9) — 반전 조건 φ_s = 2φ_fp ★
- **문턱 반전점**: φ_s = 2φ_fp 되는 교차점. 표면 전자농도 = bulk 정공농도.
- **문턱전압 Vₜ**: 이 상태를 만드는 게이트 전압.
- 왜 2배? bulk에서 E_Fi가 E_F보다 +φ_fp 위 → 표면을 n형으로 뒤집으려면 −φ_fp까지 → 총 2φ_fp 이동.

### 반전 후 공핍폭이 최대로 고정되는 이유 (교재 설명)
- 문턱 넘으면 표면 전자농도가 φ_s에 **지수함수적으로 폭증** → 추가 전하는 거의 반전층이 받음 → 공핍폭 x_d는 거의 안 늘고 **최대값 x_dT에 고정**.

### 식 (10.6) — 최대 공핍폭 x_dT
```
x_dT = √( 4·ε_s·φ_fp / (e·N_a) )     (식10.5에 φ_s=2φ_fp 대입)
```

**정리:**
```
φ_s < 2φ_fp : 공핍 (x_d 증가)
φ_s = 2φ_fp : 문턱 반전점 → 게이트 전압=Vₜ, 공핍폭=x_dT(최대)
φ_s > 2φ_fp : 강반전, 전자 폭증, x_dT 고정
```

## 보충 개념: 열평형이 깨지는 경우
| 원인 | 결과 |
|------|------|
| 전압 인가(전류 흐를 때) | E_F 분리 → 준페르미 E_Fn, E_Fp |
| 빛 조사 | 과잉 캐리어 |
| 온도 구배 | 열전류 |
| 캐리어 주입 | 과잉 캐리어 |
- 기준은 "전압"이 아니라 **"순 전류가 흐르느냐"**.
- MOS 커패시터(게이트 전압만): 산화막이 막아 전류 0 → 평형 유지.
- MOSFET(V_DS 인가): 채널에 실제 전류 → 평형 깨짐 → 준페르미 준위 E_Fn ≠ E_Fp.
